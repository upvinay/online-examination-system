# online-examination-system
Java Swing and MySQL based online examination system with student, admin, exam and result management.

# Online Examination System

A desktop-based online examination system developed using
Java Swing and MySQL.

## Features

- Student Registration
- Student Approval
- Admin Login
- Exam Management
- Question Management
- Randomized Questions
- Countdown Timer
- Answer Navigation
- Negative Marking
- Automatic Submission
- Result Generation
- Scorecard

## Technologies

- Java
- Java Swing
- JDBC
- MySQL
- OOP
- SQL

## Modules

### Admin
- Manage Students
- Manage Exams
- Manage Questions
- View Results
- Schedule Exams

### Student
- Registration
- Login
- Take Examination
- View Result

## Database

MySQL database containing:

- students
- exams
- questions
- student_answers
- results

## How to Run

1. Install Java JDK.
2. Install MySQL.
3. Create the database.
4. Import `examclone.sql`.
5. Configure the database connection.
6. Open the project in NetBeans.
7. Add the MySQL JDBC driver.
8. Run the application.
